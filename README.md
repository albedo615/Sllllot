# Sllllot

ブラウザで遊べるオリジナルのパチスロ（Aタイプ風）です。

## 遊び方

| 操作 | キー | 画面 |
| --- | --- | --- |
| MAX BET（3枚） | `B` / `↑` | MAX BET ボタン |
| レバーオン（BETも自動） | `Space` / `Enter` | LEVER ボタン |
| 左・中・右リール停止 | `J` `K` `L` / `←` `↓` `→` | 緑の停止ボタン |

URL に `?debug` を付けると、内部の設定・成立フラグが表示されます。

## 仕様

- 3リール・21コマ、5ライン有効、1ゲーム3枚掛け
- 役と払い出し

  | 役 | 図柄 | 払い出し |
  | --- | --- | --- |
  | BIG BONUS | 7-7-7 | ボーナス中 300枚を超えるまで |
  | REGULAR BONUS | BAR-BAR-BAR | ボーナス中 100枚を超えるまで |
  | ベル | ベル揃い | 8枚（ボーナス中は15枚） |
  | スイカ | スイカ揃い | 15枚 |
  | チェリー | 左リールにチェリー | 2枚（ラインごと） |
  | リプレイ | リプレイ揃い | もう1ゲーム無料 |

- レバーオン時に 0〜65535 の乱数で抽選（`src/game/lottery.ts`）
- ボーナスは揃うまで持ち越し。当選したゲームの第3停止後に「★ BONUS ★」ランプが点灯（後告知）
- リール制御（`src/game/control.ts`）: 最大4コマすべり。成立していない役は絶対に揃えず、成立している役はできるだけ引き込む
  - リプレイ・ベルはどこを押しても揃う
  - 7・BAR・スイカ・チェリーは目押しが必要
- 設定1〜6。適当押しでの機械割は約 92%（設定1）〜 105%（設定6）

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # リール制御・機械割のテスト
npm run build    # dist/ に出力
```

`main` に push すると GitHub Actions がテストとビルドを行い、GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく必要があります）。
